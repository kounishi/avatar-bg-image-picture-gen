# avatar-bg — YouTube アバター動画の背景画像 自動作成ツール

ブログ記事の URL・シナリオテキスト・アバター合成動画（透過 mov など）を渡すと、

1. ナレーションを音声認識してシナリオの各文が **何分何秒** に話されているかを特定
2. 内容のまとまりごとにシーンを分け、**作成する背景画像の枚数とタイミングを提示**
3. 確認後、背景画像（タイトル／解説スライド／記事内画像＋要点）を作成し、**隙間なく** 差し込み
4. 次の形で出力

| 出力 | 内容 |
|---|---|
| `images/scene_001.png …` | 背景画像（動画サイズちょうど） |
| `timeline.csv` / `timeline.json` | 何分何秒〜何分何秒にどの画像か（フレーム番号つき） |
| `timeline_resolve_fcp.fcpxml` | DaVinci Resolve / Final Cut Pro に読み込めるタイムライン |
| `timeline_premiere.xml` | Premiere Pro に読み込めるタイムライン（FCP7 XML） |
| `<メディア名>_with_bg.mp4` | 背景＋透過アバター＋音声を合成した完成動画 |
| `thumbnail.jpg` / `thumbnail.png` | YouTube サムネイル（1280x720。チャンネル名＋記事タイトル＋アバター） |

## セットアップ（初回のみ）

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

必要なもの: Python 3.9 以上、ffmpeg（PATH に通っていること）。
音声認識モデル（faster-whisper）は初回実行時に自動でダウンロードされます。

## 使い方

### まとめて実行（枚数を確認してから作成）

```powershell
.\.venv\Scripts\python -m avatar_bg run `
  --media  "D:\video\avatar.mov" `
  --script "D:\video\scenario.txt" `
  --url    "https://example.com/blog/article" `
  --minutes 8
```

枚数とタイミングの一覧が表示され、`y` を入力すると作成・差し込みに進みます。

### 2段階で実行（内容を手直ししたい場合）

```powershell
# 1) 枚数・タイミング・スライド内容を算出（画像はまだ作らない）
.\.venv\Scripts\python -m avatar_bg plan -m avatar.mov -s scenario.txt -u https://... -o out\vol01

# 2) 必要なら out\vol01\plan.json を編集（title / bullets / type など）

# 3) 画像作成・差し込み・出力
.\.venv\Scripts\python -m avatar_bg render -o out\vol01
```

### 2人のアバターの掛け合い動画

`--media` にアバター動画を 2 つ指定すると、2人掛け合いモードになります（1つなら従来どおり 1 人用）。

```powershell
.\.venv\Scripts\python -m avatar_bg run `
  --media  "D:\video\joined.jahic-chan-001.mov" "D:\video\joined.etc-bouya-001.mov" `
  --script "D:\video\掛け合い台本.txt" `
  --url    "https://example.com/blog/article"
```

- **台本の形式**：1 行ずつ `話者ID,セリフ`（`話者：セリフ`、`話者「セリフ」` も可）。
  話者IDを含むファイル名の動画が、その話者のアバターとして自動で対応づけられます。
- **配置**：台本で先に話す人が左下隅、もう一人が右下隅。1人用より小さく（見えている高さ＝画面の半分）表示し、
  解説スライドや記事画像は2人の間の中央に表示します。ショート版は2人とも下部に並べ、解説はその上に表示します。
- **シーンの区切り**：先に話す人（聞き手）の発言の始まりを区切りの候補にするので、質問と答えが 1 枚にまとまりやすくなります。
  記事の見出しが合わないシーンは質問文をタイトルにし、答えの文を箇条書きにします（「そのとおり。」などの相づちは除きます）。
- **音声**：2つの動画に同じ会話音声が入っている場合は 1 本分だけ使います。
  それぞれに本人の声だけが入っている場合は自動でミックスします。
- **サムネイル**：2人を右側に並べて配置し、表情 3 パターンは2人とも同じパターンでそろえます。
- 出力フォルダの既定は `output\<台本のファイル名>`、編集ソフト用 XML ではアバターが 2 本のトラックに入ります。

| オプション | 既定 | 説明 |
|---|---|---|
| `--duo-avatar-height` | `0.5` | 2人掛け合いのアバターの見えている高さ＝画面高さ×この値 |
| `--shorts-duo-avatar-height` | `0.3` | 2人掛け合いのショート版のアバターの高さ |

## 主なオプション

| オプション | 既定 | 説明 |
|---|---|---|
| `--size` | `1920x1080` | 動画サイズ。`4k`, `720p`, `shorts`（1080x1920）なども可 |
| `--target-sec` | `20` | 背景 1 枚あたりの目安秒数。大きくすると枚数が減る |
| `--min-sec` / `--max-sec` | `8` / `45` | 1 枚の最短・最長秒数 |
| `--image-threshold` | `0.2` | 記事内画像を採用する類似度の下限。上げると記事画像が減り解説スライドが増える |
| `--max-article-images` | `99` | 記事内画像の最大使用枚数 |
| `--whisper-model` | `small` | `base` で高速化、`medium` で高精度化。`none` で音声認識を使わず無音検出で推定 |
| `--theme` | `dark` | `light` も可 |
| `--no-title-card` | | 冒頭のタイトル画像を作らない |
| `--no-mp4` | | 合成済み mp4 を作らない（画像と XML だけ） |
| `--avatar-pos` | `bottom-right` | 透過アバターの配置。`bottom-left` / `center` / `original`（元動画のまま中央） |
| `--avatar-height` | `0.8` | アバターの見えている部分の高さ＝画面高さ×この値。小さくするとアバターが小さくなる |
| `--avatar-margin` | `0.02` | 画面の端からの余白（画面幅に対する割合） |

### ショート動画（縦 1080x1920）版

横動画を作るとき、同じシーン構成・同じタイミングのショート版も `出力フォルダ\shorts\` に自動で出力されます
（画像・タイムライン・XML・mp4 一式）。アバターは下部中央に画面高さの約4割で配置し、
文字は YouTube ショートの UI（上部の検索バー、右側のボタン列、下部の説明文）を避けて上半分に配置します。

| オプション | 既定 | 説明 |
|---|---|---|
| `--no-shorts` | | ショート版を出力しない |
| `--shorts-avatar-pos` | `center` | ショート版のアバター配置（`bottom-right` / `bottom-left` も可） |
| `--shorts-avatar-height` | `0.42` | ショート版のアバターの高さ＝画面高さ×この値 |

ChatGPT で作った画像をショート版に使う場合は、縦長で作って `custom\shorts\scene_03.png` のように置いてください
（横長用の `custom\scene_03.png` はショート版には使いません）。
YouTube ショートとして投稿できるのは 3 分以内の動画です。

### サムネイル

`render`（`run`）の最後に、`thumbnail.jpg`（1280x720）と、ショート版用の `shorts\thumbnail.jpg`（1080x1920）を作ります。

- **チャンネル名**：左上の赤い帯（既定「JAHICニュースCh」）
- **記事タイトル**：先頭の【…】は黄色いタグに、長いタイトルは途中の空白でメイン（白）とサブ（黄）の2段に分けて、括弧や中黒の位置で折り返します
- **アバター**：透過動画から1コマを切り出して白フチをつけ、右側（ショート版は下側）に大きく配置します
- **背景**：記事のアイキャッチ画像、なければ最初の横長の記事内画像（文字側を暗くして読みやすくします）

#### 表情 3 パターンから選ぶ

アバターの表情を変えた 3 パターンを作ります。

| 番号 | 表情 | ファイル |
|---|---|---|
| 1 | 標準の笑顔（いちばん典型的な表情） | `thumbnail_1.jpg` |
| 2 | 口を大きく開けた笑顔 | `thumbnail_2.jpg` |
| 3 | 口を閉じた笑顔 | `thumbnail_3.jpg` |

- `thumbnail_choices.jpg` に 3 つを並べた比較画像が出ます。
- 選んだもの（既定は 1）が `thumbnail.jpg` になります。
- `run` を確認ありで実行した場合は、作成後に番号を聞かれます。
- 動画全体から 48 コマを取り出し、頭の揺れを補正してから両目（瞳）を探し、その下で口の位置を見つけます。
  口の縦の開き具合と、口の中（舌など）が見えているかでコマを選び、まばたき・半目のコマは除外します。

あとから選び直す場合（作り直さずに `thumbnail.jpg` を差し替えるだけなので一瞬で終わります）：

```powershell
.\.venv\Scripts\python -m avatar_bg thumb -o output\vol01 --pick 2
```

サムネイルを作り直す場合：

```powershell
.\.venv\Scripts\python -m avatar_bg thumb -o output\vol01 --thumb-title "タイトルを短くした文言" --thumb-avatar-time 75
```

| オプション | 説明 |
|---|---|
| `--channel` | チャンネル名（既定 `JAHICニュースCh`） |
| `--thumb-title` | サムネイルの文言（既定は記事タイトル）。`【タグ】メイン サブ` の形で書くと、タグ・2段表示になります |
| `--pick` | 使う表情の番号（1〜3） |
| `--thumb-avatar-time` | アバターのコマを選ぶ位置（秒）。その前後約2秒から 3 パターンを選びます（既定は動画全体から） |
| `--no-thumbnail` | `render` / `run` でサムネイルを作らない |

`thumb` で指定した値は `plan.json` の `thumbnail` に保存されます。背景を差し替えたい場合は
`custom\thumbnail_bg.png` を置いてください（ChatGPT で作った画像なども使えます）。

アバターの配置は、動画の余白ではなく**アルファから検出したキャラクターの輪郭**を基準にします。
上半身だけの素材は下端を画面下に合わせ、右下配置なら輪郭の右端が画面右端から余白分の位置に来ます。
配置結果は `plan.json` の `avatar_layout`（x, y, w, h, scale）に保存され、合成 mp4 と編集ソフト用 XML の両方に反映されます。

## シナリオの書き方のコツ

- 見出し行（`【導入】`、`## 見出し`、`■ 見出し` など）を入れると、そこで必ず画像が切り替わり、スライドのタイトルになります。見出し行は読み上げられていなくても問題ありません。
- 空行で段落を区切ると、段落の切れ目で画像が切り替わりやすくなります。

## ChatGPT で作った画像を使う場合（任意）

`plan` 実行後に `chatgpt_prompts.md` にシーンごとのプロンプトが出力されます。ChatGPT（サブスク）で画像を生成して
`<出力フォルダ>\custom\scene_03.png` のように保存し、`render` を実行するとそのシーンの背景に差し替わります。
プロンプトにはアバターが重なる側を空けるよう指示が入っています。

## 仕組みのメモ

- 透過アバターのアルファから不透明な範囲を検出し、文字や画像をアバターと重ならない側に配置します。
- 記事内画像は、画像の周辺（見出し・前後の段落・alt・キャプション）とナレーションの文字の一致度でシーンに割り当てます。1 枚の画像は 1 回だけ使います。
- シーンの境界は「前の文の話し終わり」と「次の文の話し始め」の中間で、フレーム単位で前後のシーンがぴったりつながります。
- 透過なしの動画はアバターを右下にワイプ表示、m4a など音声のみの場合は背景画像だけで動画を作ります。
- 記事内の画像を使う場合は、元記事の著作権・利用規約を確認してください（画像には出典ドメインを表示しています）。
